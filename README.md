# DCUGen# Character Creation Tool

## Version 1.0.3 QA

This Character Creation Tool is designed to streamline the process of generating characters for role-playing games. It provides a GUI interface to enter character details, generate random attributes, and export the data to a formatted character sheet.

### Features

- Interactive GUI built with Tkinter
- JSON-based data storage for easy updates and management
- Export to Excel for a formatted character sheet
- Randomized gadget and equipment generation
- Database functionality for saving and loading sessions

### Requirements

- Python 3.7 or higher
- Tkinter library (usually included with Python)
- openpyxl library for Excel file manipulation
- sqlite3 for database functionality
